⚡ Tốc Độ CPU Thuần

~728.8 ms trên tập Test và ~1098.5 ms trên tập Development. Vector hóa bằng np.bincount giúp tăng tốc 10x so với vòng lặp.

🛡️ Chống Gian Lận (RULE.md)

100% tự cài đặt các thuật toán cốt lõi trong src/core/. Tuyệt đối không dùng cv2.Canny, cv2.HoughLines, cv2.threshold.

🎯 Độ Chính Xác

Nâng tỷ lệ phát hiện tài liệu từ 23.1% (OpenCV Contour) lên 80.8% trên tập Test nhờ cơ chế tích lũy bằng chứng toàn cục của Hough.
